# IMPERIUM: Age of Crowns

Original turn-based grand strategy game for Android (landscape), built in Godot 4.7.2 / GDScript. English + Turkish.

* 410 provinces + 34 sea zones, 7 scenarios (1066 → 1900), 9 government types, 92 technologies, deep diplomacy, supply-based warfare, layered AI, scenario editor, hotseat, deterministic saves.
* Ads: a single bottom adaptive banner (AdMob, test ids by default, UMP consent). No interstitial/rewarded/app-open.

**Start here:** `IMPLEMENTATION_STATUS.md` (what exists / what is unverified), `TEST_REPORT.md` (real results), `RELEASE_CHECKLIST.md`, `docs/ADMOB_SETUP.md`, `CLAUDE.md` (commands), `TECHNICAL_ARCHITECTURE.md`.

Run: open in Godot 4.7.2, or `godot --path .`. Tests: `godot --headless --path . res://tests/test_runner.tscn`.
Status: desktop-verified only; Android APK/AAB build and device testing still to be done (see RELEASE_CHECKLIST.md). Licences: ASSET_LICENSES.md. Privacy template: docs/PRIVACY_POLICY_TEMPLATE.md.
